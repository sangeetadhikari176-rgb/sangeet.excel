Excel Functions I Use

These are the core Excel functions I use daily to clean and transform messy data into structured, usable spreadsheets.

🔤 TRIM — Extra Space Removal
=TRIM(A2)
Removes all extra spaces from text — leading, trailing, and double spaces between words. Essential when data comes from copy-paste or web sources.
Before: "  Sangeet  Adhikari  " → After: "Sangeet Adhikari" ✓
🧷 CLEAN — Hidden Character Removal
=CLEAN(A2)
Removes non-printable characters — line breaks, tab characters — that come hidden in data exported from databases or websites.
Before: "Sangeet Adhikari" → After: "Sangeet Adhikari" ✓
🔄 SUBSTITUTE — Text Replacement
=SUBSTITUTE(A2,"-","")
Replaces specific text inside a cell — fix typos, replace old codes with new ones, or remove unwanted characters like dashes or slashes.
"9876-543210" → "9876543210" ✓
🔠 PROPER — Text Case Fix
=PROPER(TRIM(A2))
Converts text to proper title case. Used with TRIM for double cleaning power. Perfect for name columns.
"SANGEET adhikari" → "Sangeet Adhikari" ✓
🔍 Find & Replace
Ctrl + H → Find: "old" → Replace: "new"
Bulk-replaces text across thousands of rows in seconds. Useful for correcting misspellings, standardizing category names, and fixing common errors fast.
"delhi" → "Delhi" across all 5,000 rows in 2 seconds ✓
❌ Remove Duplicates
Data → Remove Duplicates → Select Columns
Removes duplicate rows from Excel in one click. Can target specific columns so only true duplicates are removed, keeping unique records safe.
10,000 rows → 847 duplicates removed → 9,153 unique records ✓
